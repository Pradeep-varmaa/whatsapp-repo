Workflow Builder: Elements, Fields & Validation Rules

Complete Reference Guide for Studio Nodes and Decision Logic

The WhatsApp Engine visual workflow builder is a node-based DAG (Directed Acyclic Graph) system built on ReactFlow. It allows enterprise teams to construct multi-turn interactive conversational agents with API integrations, calendar pickers, time slot reservations, and intelligent conditional branching.

⚡ 1. Entry & Communication

Trigger monitors inbound WhatsApp keywords. Message sends outbound rich text with dynamic token replacements.

🔘 2. Interactive Selection

Quick Buttons (1-3 click options) and Menu List (up to 10 rows or live API dynamic array mapping).

🔀 3. Logic & Decision

Condition (If/Else) branches flows by evaluating variables against 9 logical comparison operators.

❓ 4. Data Capture

Ask Node captures text, numbers, emails, calendar dates, or time slots with automatic normalization.

🌐 5. Webhooks & Backend

Server API makes REST HTTP requests with allowlist SSRF protection and discrete Success/Error ports.

🏁 6. Lifecycle

End Flow terminates the active customer session cleanly and updates execution metrics.

Trigger Node (Workflow Entry Point)

Listens for customer inbound keywords to start an automated flow

⚡ Trigger Node
Keywords: start, hi, hello, menu
Description: General customer entry trigger
● Output: (next)

📝 Configurable Fields

FieldTypeReqDescription
keywordStringNoComma-separated keywords (case-insensitive) e.g. hi, book, start
descriptionStringNoInternal administrative notes describing when this triggers.

🛡️ Validation Rules (Graph Publisher)

• Exactly 1 Trigger node must exist in the workflow graph.
• The next port must be connected to an outgoing node.
• No incoming connections are permitted (Trigger is always the root).

💬 WhatsApp Runtime Behavior

When a user messages your WhatsApp Business number, the engine matches the incoming text against active triggers. Upon a match, a new run record is stored and execution immediately moves to the node connected on next.

💬 WhatsApp Runtime Behavior

Pauses execution in waiting_reply state. When the user taps a button, WhatsApp sends a webhook with the button ID. The runner records the choice in selected_row_id and follows that button's connected port.

Date Picker Component (Calendar Flow)

Native WhatsApp interactive list calendar for booking and reservations

📅 Date Picker
"Please select your appointment date:"
WhatsApp List: Today, Tomorrow, Next 5 Days
Save: {{selected_date}} (ISO YYYY-MM-DD)
● Output: (next)

💬 How It Appears on WhatsApp

Because WhatsApp has no OS-native HTML5 date picker widget, the engine delivers an Interactive List Message containing:
• Today (e.g. Today (Mon, Nov 17))
• Tomorrow (e.g. Tomorrow (Tue, Nov 18))
• Next 5 Business Days calculated automatically
• Plus fallback text prompt support for manual replies (e.g. 25/11/2026)

🔄 Parsing & ISO Normalization

User types 25/11/2026 or selects Tomorrow → engine normalizes to 2026-11-25.
Stored in both your custom variable and standard {{selected_date}}.

Branch conversation flow based on variable comparison logic

⚙️ 9 Logical Comparison Operators

OperatorLogicExample

not_equalsInequality check{{status}} != "CANCELLED"
containsSubstring search{{message}} contains "urgent"
greater_thanNumeric / alphabetical comparison{{total}} > 100
less_thanNumeric comparison{{age}} < 18
is_emptyChecks if null, undefined, or empty{{code}} is null
is_not_emptyChecks if variable has any value{{notes}} has value
existsChecks if variable is declared{{api_result}} exists

🛡️ Validation Rules

• variable is required.
• BOTH output ports must be connected: true (If branch) and false (Else branch).

Server API Node (HTTP Webhooks & Field Mapping)

Real-time HTTP requests to external CRM, databases, and ERP backends

🌐 Server API Call
POST api.crm.com/v1/orders
Save JSON: {{api_result}}
Mapped: response.id -> order_id
✓ Success ✕ Error

🔒 Security & SSRF Protection

All destination hosts must be pre-approved in the Webhook Allowlist. Unregistered hosts trigger immediate security blocks and take the Error branch. Built-in 5000ms timeout prevents hangs.

🛡️ Validation Rules

• URL must be a valid HTTP/HTTPS endpoint.
• Both ports must be connected: success (HTTP 2xx) and error (4xx, 5xx, or network failure).

Archive Workflow

🔒 Workflow Archiving (Soft Delete)

Clicking the trash button on any workflow card opens an Ant Design modal with full details (name, version, trigger keyword) and an explanation of the archive action.
• Calls DELETE /api/workflows/[id] which runs: UPDATE workflows SET status = 'archived'.
• The agent stops responding to WhatsApp incoming messages immediately.
• All customer messages, executions, and analytics remain permanently preserved.

🔄 Restore & Step Level Protection

• Restore Endpoint: POST /api/workflows/[id]/restore moves an archived flow back to draft.
• Step Deletion Guard: Inside the canvas editor, clicking Delete Step triggers a warning modal confirming that connecting ports will be disconnected.
